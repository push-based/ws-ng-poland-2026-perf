# Push-Based Angular Performance Workshop

## Installation Instructions

**System Requirements**

* `node > 20`
* `npm > 8`

**Clone and install**

```bash
git clone https://github.com/push-based/ws-ng-perf-ngde-2025.git

cd ws-ng-perf-ngde-2025
npm install

# (optional) if the step before didn't work, please try the following
npm install --force
```

**Run the application**

```bash
npm run start
```
